# The Undertow

A real-time water caustics simulation using Three.js, featuring interactive ripple effects and underwater light refraction.

**Based on**: [threejs-caustics](https://github.com/martinRenou/threejs-caustics) by Martin Renou  
**Original demo**: https://martinrenou.github.io/threejs-caustics  
**Technical article**: https://medium.com/@martinRenou/real-time-rendering-of-water-caustics-59cda1d74aa

## Enhancements in This Fork

- ✅ Updated to Three.js v0.170.0 (from v0.117.0)
- ✅ Migrated to Vite for modern development workflow
- ✅ Converted to ES6 modules
- ✅ Full offline support (no CDN dependencies)
- ✅ Optimized bundling and hot module replacement
